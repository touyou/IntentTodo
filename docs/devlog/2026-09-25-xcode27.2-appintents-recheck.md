# Xcode 27.2 beta の SDK 差分で App Intents 周りを棚卸しした件（#57）

現在の結論は [docs/APP_INTENTS_API_COVERAGE.md](../APP_INTENTS_API_COVERAGE.md) と
[skills/](../../skills/README.md) にある。ここには **27.2 beta で何をどう測って、
[RC の記録](2026-09-10-xcode27-rc-recheck.md)のどれが変わり、どれが変わらなかったか**を残す。

## 環境

**3 点で取った**（27.1 を飛ばすと「27.2 で入った」と言い切れないため）。

| | Xcode | build | iOS SDK | AppIntents `user-module-version` |
|---|---|---|---|---|
| 比較元 | 27.0 RC | 27A266a | `iPhoneOS27.0.sdk` | `301.0.51.1.104` |
| 中間 | **27.1** | **27A9269** | `iPhoneOS27.1.sdk` | **`301.0.51.1.104`**（同一） |
| 比較先 | 27.2 beta | **27B5019j** | `iPhoneOS27.2.sdk` | **`301.1.9.1.101`** |

実測日 2026-09-25。`xcode-select` は切り替えていない。**ビルドは 1 回も走らせていない**（§4）。

> **`/Applications/Xcode.app` は 27.0 RC のまま**で、PATH の先には 27.1 beta の
> `Contents/Developer/usr/bin` が入っている（RC のときと同じ状態）。素の `xcodebuild -version` は
> **PATH 側の 27.1** を答えるので、`Xcode.app` の中身を 27.1 だと読み違えた。
> SDK を比べるときは `-version` ではなく**アプリバンドルのパスを直接指す**。

## 測り方

swiftinterface は宣言の並び順が版ごとに動くので、素の `diff` は 2.3MB 出て読めない。
**行をソートしてから差分を取る**と、順序変更が消えて増減だけが残る:

```bash
diff <(sort $A | sed 's/^ *//' | grep -v '^$') <(sort $B | sed 's/^ *//' | grep -v '^$')
```

**27.0 → 27.1 の差分は 0**（iOS / watchOS / `AppIntentsTesting` すべて。`user-module-version` も同一）。
つまり **27.1 は App Intents に何も入れていない**ので、以下の差分はすべて 27.2 のもの。
availability 側でも裏が取れていて、`anyAppleOS 27.1` / `iOS 27.1` で切られた宣言は**どの SDK にも 0 件**
（マイナー版での availability 自体は使われている——`anyAppleOS 26.4` が 16 件ある）。

27.1 → 27.2 は、iOS の `AppIntents.swiftinterface` 16,797 行に対して **差分 33 行**。
watchOS スライスも同じ 33 行（= watch 固有の変化は無い）。
`WidgetKit` / `CoreSpotlight` / `VisualIntelligence` / `_AppIntents_SwiftUI` / `ActivityKit` は**差分 0**。
SDK のフレームワーク一覧の増分も `FoundationModelsCore` と `_NearbyInteraction_SwiftUI` の 2 つだけで、
App Intents 系は増えていない。

## 1. 増えた公開 API は 3 つ（いずれも `anyAppleOS 27.2`）

### `AssistantSchemaEnum.caseDisplayRepresentations` の既定実装

```swift
@available(anyAppleOS 27.2, *)
extension AssistantSchemaEnum {
  public static var caseDisplayRepresentations: [Self : DisplayRepresentation] { get }
}
```

schema 適合 enum（`TodoListType` / `TodoLocationTriggerEvent`）は、27.2 以降を deployment target に
できれば宣言を落とせる。**何の文言が入るかは未確認**（Apple が schema の語彙を持っているなら
ローカライズ込みで載る可能性があるが、これは推測）。本アプリは 27.0 が下限なので**今は宣言必須**。

### `@UnionValue` の `@Parameter` オーバーロード 2 系統

`IntentParameter where Value.ValueType: _IntentValueRepresentable`（= `@UnionValue` 型）に

- `default:` 付きイニシャライザ
- コレクション用の `size:`（`IntentCollectionSize` / `[IntentWidgetFamily: IntentCollectionSize]`）

が追加された。27.0 には `default:` が無く、union をウィジェット設定のコレクションとして
サイズ指定する形も書けなかった。**戻り値としての `@UnionValue` は 27.0 のままで足りている**ので、
`TodoOrCategory` の現状に影響は無い。

### `AppIntentsTesting.DynamicPropertyPath.get(as:)`

```swift
@available(anyAppleOS 27.2, *)
public func get<T>(as type: T.Type = T.self) async throws -> T where T : IntentValueConvertible
```

既存の `as(_:)` / 添字と**構造的な違いは `async` だけ**。27.1 のドキュメントセットには載っていない。
非同期に解決される属性（`TodoAppEntity.subtaskProgress` の `@DeferredProperty`）は同期の読み出しでは
手が無いので**候補としては合う**が、そう書いてあるわけではない。`[inferred]` のまま #57 に置く。

## 2. 変わっていないもの（RC で出した結論はすべて有効）

| 項目 | RC 27A266a | 27.1 / 27.2 beta |
|---|---|---|
| `SystemShortcut` の公開イニシャライザ | 無い | **無い** |
| `_ModelDelegationIntent` / `IntentResponseStream` | 下線付き + `@_documentation(visibility: internal)` | **同じ** |
| `IntentSystemContext` のメンバ | `preciseTimestamp` / `isVoiceOnly` / `locale` | **同じ 3 つ** |
| `AppEntityContext` のファクトリ | `.audio(_:)` のみ | **`.audio(_:)` のみ** |
| `AudioContext` | `.nowPlaying` のみ | **`.nowPlaying` のみ** |
| negative phrases API | あり（未採用） | **同じ** |
| assistant schema の名前一覧 | — | **増減 0**（`AppSchema.Entity("…")` 等のリテラルが完全一致） |
| マクロ一覧 | — | **増減 0** |
| watchOS の assistant schema | unavailable | **unavailable**（watch スライスの差分が iOS と同一） |

`AppSchema.photos.asset` の availability が `anyAppleOS 27.0` → `iOS 18.0` に**下がって**いたのが
唯一の既存宣言の変更だが、写真ドメインなので本アプリには関係しない。

  `@UnionValue` / `.reminders.listType` / テストの 3 行に 27.2 の追加分を書いた

- `skills/app-intents-testing/` — `get(as:)`

## 4. 測っていないもの

**SDK の宣言しか見ていない。** 以下はビルドしないと分からないので、今回は手を付けていない
（ワークツリーで別作業が走っていたため、重いビルドを重ねるのを避けた）:

- `PlaceDescriptor` の SSU training バグ（FB24548956 / #57）が 27.2 で直ったか
- App Schema と watch ターゲットのメタデータ上書き（FB24570185 / #57）が 27.2 で直ったか
- schema 適合の**要求内容**（必須パラメータ名・型）が動いていないか。
  これは swiftinterface には出ず、マクロ展開＝ビルドでしか出ない
- `get(as:)` が実際に `@DeferredProperty` を読めるか

やるときは RC のときと同じ形（`-derivedDataPath /tmp/…` でクリーンビルド、
`inspect_appintents_metadata.py` で出荷メタデータを確認）で、`DEVELOPER_DIR` を 27.2 beta に向ける。
`test` には `CODE_SIGNING_ALLOWED=NO` を付けない。
