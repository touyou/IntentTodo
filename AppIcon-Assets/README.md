# AppIcon 素材（Icon Composer 用）

IntentTodo のリスト行（**丸チェック + テキスト行 + 星**）を 3 行並べた前景アートワーク。
背景は透過。Icon Composer 側で背景・ガラス・影・角丸を付ける運用を想定しています。

## ファイル

| ファイル | 内容 | 用途 |
|---|---|---|
| `icon-foreground-color.png` | カラー版（アプリ UI と一致。緑チェック / 金星 / グレー枠、状態のミックス）。1024×1024 透過 | **採用版。これを Icon Composer に取り込む** |
| `icon-foreground-mono.png` | 単色版（同じ構図を 1 色 `#1C1C1E` で）。1024×1024 透過 | Icon Composer でティント/ガラスをかける場合 |
| `render.swift` | 上記 PNG を生成する CoreGraphics ソース | 調整・再生成用（下記コマンド） |

> **なぜ SVG ではなく PNG か**: Icon Composer は編集時と**ビルド時でSVGラスタライザが異なり**、`mask` / `use` / `defs` を使った SVG がビルド後に潰れる（左上に寄る / 一部欠落）現象があった。PNG なら描画結果がそのまま入るので確実。

## 3 行の状態（アプリの ON/OFF に対応）

| 行 | 丸 | テキスト | 星 |
|---|---|---|---|
| 1 | 緑塗り + チェック**切り抜き**（完了） | 薄グレー（done） | 金・塗り（お気に入り） |
| 2 | グレー枠（未完了） | 濃グレー | グレー**枠** |
| 3 | グレー枠（未完了） | 濃グレー | 金・塗り（お気に入り） |

- 丸は塗り・枠とも**外径 62px で統一**（見た目のサイズを揃え済み）。
- チェックは緑円から**切り抜き**（透過穴）。Icon Composer では下の背景レイヤーが透けて見える（アプリの白チェックと同じ見え方。背景が濃い場合はその色が透ける点に注意）。

いずれも 1024×1024、中央にコンテンツを配置（Apple のアイコングリッド安全域内）。

## Icon Composer への取り込み

1. Icon Composer で `IntentTodo/AppIcon.icon` を開く
2. `icon-foreground-color.png` をドラッグしてレイヤーに追加（既存レイヤーがあれば置き換え）
3. 背景フィル（現状 `display-p3:0.949,0.949,0.969`）はそのまま、または好みのグラデーションに
4. 単色版を使う場合はレイヤーに Tint / Glass を適用して質感を出す

## 色（カラー版）

- 完了の丸: `#34C759`（アプリの緑と一致）
- 星（塗り）: `#FFC400`（お気に入り金）
- 枠（未完了の丸 / 枠の星）: `#8E939B`（グレー）
- テキスト行（未完了）: `#5B6068` / テキスト行（完了・薄）: `#C2C8D0`

## 再生成 / 調整

色・レイアウトを変えたいときは `render.swift` の定数を編集して再実行:

```sh
cd AppIcon-Assets
swift render.swift .
```

`icon-foreground-color.png` と `icon-foreground-mono.png` が上書き生成される。
